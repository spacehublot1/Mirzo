# Jarvis — ko'p-AI yordamchi

Bitta savolni bir nechta AI'ga (ChatGPT, Gemini, DeepSeek) parallel yuboradi,
keyin tanlangan "bosh miya" ularning javoblarini birlashtirib yagona eng yaxshi
javobni beradi. Ovozli boshqaruv (gapirib so'rash) va javobni ovoz bilan o'qish bor.

## O'rnatish
1. APK'ni Actions → Artifacts dan yuklab o'rnating.
2. Sozlamalarga kirib, kamida bitta AI kalitini kiriting:
   - ChatGPT (OpenAI): platform.openai.com
   - Gemini (Google): aistudio.google.com
   - DeepSeek: platform.deepseek.com
3. "Bosh miya"ni tanlang (javoblarni kim birlashtirsin).

## O'sib borishi
- Har suhbat xotiraga yoziladi.
- Bosh miya har javobda bitta "SABOQ" (qoida) chiqaradi, u saqlanib keyingi
  javoblarni yaxshilaydi — shunday qilib "yosh miya" vaqt o'tgani sari rivojlanadi.

Kalitlar faqat telefonning o'zida saqlanadi.
